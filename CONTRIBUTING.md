# Contributing

Спасибо за интерес к **Домашнему книжному аудитору**!

## Разработка

1. Форкните репозиторий и создайте ветку: `git checkout -b feature/my-change`
2. Установите зависимости: `npm install`
3. Запустите dev-сервер: `npm run dev`
4. Перед PR выполните:

```bash
npm run lint
npm run format
npm test
npm run build
```

## Стиль кода

- TypeScript strict
- ESLint + Prettier (конфиги в корне)
- Компоненты — функциональные, hooks
- Данные — только через Dexie (`src/db`)
- Не коммитьте `node_modules`, `dist`, локальные секреты

## Коммиты

Кратко и по делу, на русском или английском:

- `feat: ...` — новая возможность
- `fix: ...` — исправление
- `docs: ...` — документация
- `chore: ...` — инфраструктура

## Pull Request

Опишите:

- что изменено и зачем;
- как проверить;
- скриншоты UI (если есть).
