# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] — 2026-08-07

### Added

- Full library management (CRUD) with IndexedDB (Dexie)
- Home dashboard with counters, favorites, recent activity
- Search, filters, and sorting
- Statistics with Chart.js (genres, authors, timeline, status)
- Export / import: JSON, CSV, Excel
- Backup & restore, Web Share API, drag-and-drop import
- Book covers: upload, camera capture, auto-compression
- ISBN barcode scanner (html5-qrcode)
- Light / dark / system themes
- PWA: service worker, offline cache, installable, app shortcuts
- Capacitor Android configuration
- GitHub Actions CI + GitHub Pages deploy
- Unit tests for filtering
